# Changelog

Todas as mudanças relevantes deste projeto serão documentadas aqui.

## 1.1.0 - 2026-08-01

- Redesenha a tela principal com visual premium, métricas úteis e CTA refinado.
- Remove efeitos caros de blur em áreas roláveis e melhora desempenho visual.
- Adiciona componentes premium reutilizáveis para superfícies e botões.
- Moderniza cards de time e imagem de compartilhamento.
- Normaliza parsing de jogadores e remove duplicados.
- Adiciona testes de domínio.
- Organiza GitHub público com CI, release workflow, templates e documentação.
- Atualiza `applicationId` Android para `io.github.weszzy.sorteadorpro`.

## 1.0.0 - 2025-12-13

- Primeira versão pública do Sorteador Pro.
- Sorteio normal e avançado.
- Histórico local.
- Compartilhamento de resultado.
- Temas customizáveis.
