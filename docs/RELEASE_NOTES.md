# Sorteador Pro 1.1.0

## Destaques

- Visual premium com nova tela principal, cards de time refinados e imagem de compartilhamento atualizada.
- Melhor desempenho visual ao remover blur pesado de áreas roláveis.
- GitHub público organizado com CI, release workflow, templates e documentação.
- Android agora usa `applicationId` profissional: `io.github.weszzy.sorteadorpro`.

## Validação

- `flutter analyze`
- `flutter test`
- `flutter build web --release`
- `flutter build apk --release`

## Nota sobre assinatura

O APK anexado pelo GitHub Actions é um build público de preview. Para loja Android, use assinatura privada fora do repositório.
