# Security Policy

## Versões suportadas

Correções de segurança são aplicadas na versão mais recente publicada.

## Reportar vulnerabilidade

Não abra issue pública com detalhes exploráveis. Use um advisory privado do GitHub ou contato privado do mantenedor.

Inclua:

- Descrição do problema.
- Passos para reproduzir.
- Impacto esperado.
- Versão, tag ou commit afetado.

## Segredos e builds

Este repositório não deve conter chaves privadas, keystores, tokens, arquivos `.env` reais ou credenciais de loja. Builds de release publicados pelo CI são artefatos de preview assinados com configuração pública/debug. Builds de loja exigem assinatura privada fora do repositório.
